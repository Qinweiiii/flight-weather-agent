# 数据契约与推断边界

## 总体与来源

本地 CSV 导入 `flights_enriched`。现有历史库是样本，不保证覆盖整个美国航班总体，不把样本总数称为某航空公司的实际运营量。`dataset_metadata` 存在时读取来源；缺失时明确标注“历史样本（来源待核验）”。

虚拟场景由 `data/generate_demo_data.py` 生成：固定种子、90 个日期、4 个机场、每天每机场 40 个计划航班。最后 30 天 AAA 天气暴露上升，BBB/ZX 前序晚到上升，CCC 取消率上升，DDD 为稳定对照。标签用于回归，不能把该数据上的正确识别当成真实世界泛化能力。

## 指标

| 指标 | 分子/计算 | 分母与缺失 |
|---|---|---|
| 计划航班量 | COUNT(*) | 当前筛选样本 |
| 到达延误率 | ARR_DELAY >= 15 的记录数 | CANCELLED=0、DIVERTED=0 且 ARR_DELAY 非空 |
| 取消率 | CANCELLED=1 | CANCELLED 为 0 或 1 |
| 平均到达延误 | AVG(ARR_DELAY)，允许负值 | 有效到达样本 |
| 正到达延误分钟 | SUM(MAX(ARR_DELAY,0)) | 有效到达样本；提前不抵消延误 |
| 报告原因占比 | 该原因分钟 / 所有已报告原因分钟 | 仅有效且延误≥15分钟记录；展示字段完整覆盖率 |

15 分钟阈值参考 [BTS 航班正常性定义](https://www.transtats.bts.gov/OT_Delay/)。这里定义的有效到达分母是本项目分析契约，不自动等同任意外部报表分母。

天气高降水组：任一端降水 > 阈值；若未满足高组且任一端缺失，归 unknown；两个值均观测且未超阈值才归低组。日级天气关联不代表航班起降时刻暴露，历史 CSV 的天气单位与连接过程仍需源数据字典核验，因此输出相关性而非天气因果效应。

## 时间与异常

最近 N 天为 `[max_date-(N-1), max_date]`；前期为 `[max_date-(2N-1), max_date-N]`。日报 1 天、周报 7 天。实际有缺日的库仍按自然日窗口，不偷偷取 N 个有航班日期。

异常是探索性候选：两期有效样本均达到门槛；率上升至少 3 个百分点且简单正态近似 95% 差值区间下界大于 0。该区间未处理同机场/同日聚类、极端比例与多重比较，不能当作正式显著性检验。平均延误用上升 5 分钟的业务阈值，不声称统计显著。

## 原因与行动

报告原因（CARRIER/WEATHER/NAS/SECURITY/LATE_AIRCRAFT）属于航司报告分类。NAS 涵盖非极端天气、机场运行、流量和流控等，不可直接命名为机场拥堵；前序晚到是传播现象，不能直接归责航司。定义参考 [BTS 原因说明](https://www.bts.gov/explore-topics-and-geography/topics/airline-time-performance-and-causes-flight-delays)。

天气分组率差和报告原因分钟分别展示，不能混合排序。当前没有因果识别模型，也没有尾号周转链、机组合法性、维护日志或机场容量数据，不能证明某项措施解决了根因。

行动候选来自人工维护的 YAML，均需运营人员审核。先复核热点、补证据，再用同机场/航线/时段的试点和对照比较等长窗口，同时看取消率、成本与资源限制。默认 8% 只是情景参数，乘的是选中报告原因分钟，不能称为预计节省或累计已实现收益。

## 输入与执行限制

自由自然语言 SQL 仍可能产生语义错误；数据库只读边界不保证业务正确。固定 skills 使用参数绑定和白名单维度。SQL 最多返回 2000 行，超过时失败并要求聚合/缩小范围，不静默截断；SQLite VM 超过 5 秒中断。不支持写入、扩展加载和 ATTACH。
