# 当前版本上手教程

启动命令以 [README](../README.md) 为准。最短离线启动：

```bash
cd /Users/eddiel/Documents/flight-weather-agent
APP_MODE=demo PORT=5010 ./start_web.sh
```

先运行 README 中的 AAA、BBB/ZX、CCC 三种演示问题，再阅读代码。离线模式不用 Key，但仅支持固定场景；真实模型模式用 `APP_MODE=live` 并设置 `QWEN_API_KEY`。

## 阅读顺序

1. `app.py`：浏览器会话、输入校验、同用户请求锁、SSE 心跳。
2. `agent.py`：绝对路径配置、模型/演示模式、用户与会话入口。
3. `agents/workflow.py`：唯一执行图，意图与参数路由、真正并发、结果审校、checkpoint。
4. `agents/sql_agent.py` → `mcp_sql_server.py` → `tools/sql_executor.py`：推理、协议、只读执行边界。
5. `tools/metrics.py` → `tools/ops_decision_skills.py`：先看分母，再看原因排名和情景假设。
6. `agents/search_agent.py`、`agents/debate_agent.py`、`agents/critic_agent.py`：证据不足时如何拒绝过度结论。
7. `memory/long_term_memory.py`：SQLite 持久化、哈希向量召回和关键词兜底。
8. `static/app.js`：useSSEChat 与组件；修改后运行 `node scripts/build_frontend.cjs`。
9. `tests/test_regression.py` 与 `eval/`：真实执行哪些部分、替身替代哪些部分。

## 当前版本与旧版本差异

旧 SSE 手写分支绕开 LangGraph；现已统一。旧计划由独立 Planner 生成；现由实际选中路径派生。旧输出先发答案再发 trace；现 done 最后。旧长期记忆自动抽取模型知识；现只保存明确用户偏好，避免把错误回答变成跨会话事实。旧图表让 LLM 直接生成数值配置；现由查询结果确定性映射。

记忆演示：输入 `记住：我关注BBB机场`，切到 Memory 查看；开始新会话后记录仍存在。短期 checkpoint 只在进程内存中，服务重启会消失；长期 SQLite 保留。用户 ID 是本地演示身份，不是生产登录认证。
